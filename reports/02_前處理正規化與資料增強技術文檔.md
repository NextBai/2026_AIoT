# 物聯網音檔前處理正規化與資料增強技術文檔

本文件為針對物聯網語音辨識（Voice Identification / Speaker Recognition）專案所建立的**標準化前處理管線（Preprocessing Pipeline）**與**自監督學習（Self-Supervised Learning, SSL）資料增強**技術說明文檔。

---

## 一、 文檔目的與設計原則

為解決舊版前處理產生的邊界階躍爆音（Clicks）、語素腰斬、訊噪比不均與有效語音大量流失等問題，本管線採用以下現代語音聲學處理核心原則：
1. **無損聲學特徵**：統一採樣率與聲道規格，嚴格避免混疊（Aliasing）與頻譜洩漏。
2. **能量一致性（Loudness Consistency）**：透過 RMS 響度正規化，消除說話者離麥克風遠近及發音力量不同造成的偏差。
3. **語音活動檢測（VAD）與平滑加窗**：去除無效靜音，並透過 Hann 窗淡入淡出實現邊界平滑過渡（Zero Discontinuity）。
4. **多維度環境與自監督資料擴增**：結合物聯網真實邊緣噪音與 Wav2Vec 2.0 / HuBERT 的時域遮罩技術，提升模型的泛化性與強健度。

## 三、 第一階段：標準化與正規化（Normalization）

### 1. 聲道精簡（Stereo to Mono）
- **背景**：原音檔雖為雙聲道，但實測兩聲道波形相關係數為 `1.0000`（實質為單聲道錄音的 Dual-Mono 冗餘）。
- **作法**：
  $$x_{\text{mono}}[n] = \frac{x_{\text{left}}[n] + x_{\text{right}}[n]}{2}$$
  消除 50% 冗餘運算量與頻寬。

### 2. 抗混疊降取樣（Polyphase Anti-aliased Resampling）
- **標準格式**：語音辨識與聲紋辨識最通用的採樣率為 **16,000 Hz**。
- **作法**：由 48,000 Hz 降取樣至 16,000 Hz（降採樣率因子為 3）。
- **防混疊保護**：採用 `scipy.signal.resample_poly`，內部先使用 Kaiser 窗設計之 FIR 低通濾波器（截止頻率 8,000 Hz Nyquist），杜絕高頻訊號折疊造成的混疊失真（Aliasing Distortion）。

### 3. 直流偏移消除（DC Offset Removal）
- **作法**：
  $$x[n] \leftarrow x[n] - \frac{1}{N}\sum_{i=0}^{N-1} x[i]$$
  確保訊號中心軸嚴格貼合 0.0，避免在傅立葉變換時 0 Hz（DC 頻率）產生非預期的能量尖峰。

### 4. 響度正規化（RMS Loudness Normalization）
- **背景**：各說話者錄音時音量落差高達 5.0 dB，若不平衡，模型會把「音量大小」學為說話者分類特徵。
- **公式**：
  $$P_{\text{rms}} = \sqrt{\frac{1}{N}\sum_{n=0}^{N-1} x^2[n]}, \quad \text{Scale} = \frac{10^{\frac{-20}{20}}}{P_{\text{rms}}}$$
  $$x_{\text{norm}}[n] = x[n] \times \text{Scale}$$
- **數位防破音保護**：限制最大絕對峰值 $\max(|x[n]|) \le -1.0\text{ dBFS}$（約 $0.891$），確保 16-bit PCM 轉換時絕對不發生數位破音削波（Clipping）。

## 四、 第二階段：VAD 靜音切除與 3.5 秒黃金段截取

### 1. 雙門檻語音活動檢測（VAD）
- **檢測原理**：計算 30ms 幀長、10ms 步長（Hop）的短時能量（Short-Time Energy, STE）：
  $$E[m] = \sum_{k=0}^{L-1} x^2[m \cdot H + k]$$
- **動態門檻**：以該音檔最大幀能量的 $3.5\%$ 作為語音活動判定門檻。
- **過渡緩衝區**：在檢測到的首幀前與尾幀後各保留 **80ms 的自然語音過渡緩衝**，防止母音啟動階段與微弱子音尾音被硬性削除。

### 2. 能量滑動窗口尋找 3.5 秒精華段
- 原詩時長約 6~10 秒，在經 VAD 剔除頭尾靜音後的純語音段中，使用滑動步長 100ms 遍歷所有 3.5 秒區間，自動計算窗口總能量：
  $$t^* = \arg\max_t \sum_{n=t}^{t + 3.5 \times f_s} x^2[n]$$
  選取最具說話者聲學能量特徵的 3.5 秒連續語音。

### 3. 20ms Hann 窗淡入淡出（根除爆音與頻譜洩漏）
- **消除邊界不連續**：在 3.5 秒切片的最前 20ms 與最後 20ms 施加 Hann 窗淡入與淡出函數：
  $$w_{\text{fade-in}}[n] = 0.5 \left(1 - \cos\left(\frac{\pi n}{M}\right)\right), \quad n \in [0, M-1]$$
  $$w_{\text{fade-out}}[n] = 0.5 \left(1 + \cos\left(\frac{\pi n}{M}\right)\right), \quad n \in [0, M-1]$$
  其中 $M = 0.02 \times 16000 = 320$ 點。
- **實測效果**：切片起始樣本振幅 $x[0] = 0.00000$、末尾樣本振幅 $x[N-1] = 0.00000$，在梅爾頻譜圖（Mel-spectrogram）上完全消除了階躍造成的垂直脈衝雜訊。

## 五、 第三階段：數據增強與自監督學習（SSL）增強技術

為解決僅 12 條樣本極端稀疏、且單純高斯白噪無法代表真實環境的問題，設計了 6 大增強模組：

### 1. 精確目標 SNR 白噪音（AWGN, SNR = 15.0 dB）
- **動態功率匹配公式**：
  $$\text{Noise} \sim \mathcal{N}(0, \sigma^2), \quad \sigma = \sqrt{\frac{P_{\text{signal}}}{10^{\frac{\text{SNR}}{10}}}}$$
- **特點**：雜訊嚴格依據該語音的真實能量動態計算，保證 12 條音檔承受完全一致的訊噪比，杜絕因雜訊強度不均導致的模型偏差。

### 2. 物聯網邊緣設備低頻/粉紅噪音（Pink Noise, 1/f, SNR = 15.0 dB）
- **原理**：真實物聯網設備（如智慧音箱、工業網關）大多處於具備散熱風扇、空調微風或室內低頻底噪的環境，其功率頻譜密度隨頻率增加而衰減（$S(f) \propto 1/f$）。
- **實作**：使用 Paul Kellet 的 IIR 濾波器將白噪聲轉化為標準粉紅噪聲，並精準匹配至 SNR 15dB。

### 3. 自監督時域隨機遮罩（SSL Time Masking）
- **理論來源**：借鑒自當前主流自監督語音大模型 **Wav2Vec 2.0 / HuBERT / WavLM** 的 Masked Acoustic Modeling 機制。
- **實作方式**：
  - 在 3.5 秒語音中隨機選取 2 個長度介於 **80ms ～ 150ms** 的語音片段。
  - 將其時域振幅歸零，並在遮罩邊緣進行 10ms 平滑線性淡化。
- **效益**：強迫聲紋模型不能只依賴單一特徵音，而必須從上下文的聲紋共振特徵中進行重構識別，大幅提升注意力機制模型的強健性。

### 4. 物聯網麥克風頻帶濾波（Bandpass Filter, 300Hz ~ 3400Hz）
- **原理**：物聯網低成本麥克風與語音通訊協定往往具備窄頻限制（如傳統電話音頻頻寬 300Hz~3.4kHz）。
- **實作**：採用 4 階 Butterworth 帶通濾波器，濾除低於 300Hz 的次聲波與高於 3.4kHz 的高頻泛音，並自動補償能量增益。

### 5. 動態音量擾動（Volume Gain Jitter, $\pm 3.0\text{ dB}$）
- **實作**：在 $[-3.0\text{ dB}, +3.0\text{ dB}]$ 區間隨機選取增益因子：
  $$G = 10^{\frac{\Delta \text{dB}}{20}}, \quad x_{\text{jitter}}[n] = x[n] \cdot G$$
- **效益**：模擬說話者面朝麥克風時頭部微幅移動或發音輕重變化。

### 6. 時域微位移（Time Shift, $\pm 80\text{ ms}$）
- **實作**：隨機在 $[-80\text{ms}, +80\text{ms}]$ 範圍內將波形進行循環或線性平移，並將移出空缺補零。
- **效益**：破壞絕對時間戳記憶，增強卷積神經網絡（CNN / TDNN）的時間平移不變性（Time-shift Invariance）。

## 七、 總結與使用指南

- **聲紋模型特徵提取**：
  - 建議使用 `2_去頭去尾_有效音檔3到5秒/` 作為基準驗證與特徵分析集。
  - 使用 `3_數據增強與自監督增強/` 作為訓練集（資料量由 12 條擴充至 72+ 條，且涵蓋不同噪聲、遮罩與增益情況）。
- **管線復現指令**：
  若後續新增錄音音檔，只需放入 `物聯網音檔/` 資料夾，並於終端執行：
  ```bash
  python pipeline_process.py
  ```
  系統將自動完成所有三階層音檔之產出。
